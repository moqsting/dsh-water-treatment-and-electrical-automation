# 招标与价格查询

## 触发场景
- 查询设备价格与供应商
- 检索招标公告、中标结果
- 跟踪特定项目招标动态（结合每日自动化 A1）

## 数据来源（完整清单见 config\tender-sources.md，检索前先读它）
### 招标信息（公开源优先）
1. 中国政府采购网（ccgp.gov.cn）、中国招标投标公共服务平台（cebpubservice.com）、全国公共资源交易平台（ggzy.gov.cn）
2. 各省公共资源交易中心（按项目属地检索）
3. 行业站点（比地招标网、千里马、剑鱼标讯、采招网）——**需会员的只提示入口，不代查付费内容**
### 价格信息
1688、京东工业品、震坤行、西域、慧聪网、泵阀商务网、供应商官网

## 工作流（SOP）
1. 明确目标：设备名 + 规格 + 地域 + 时间窗（近 30/90 天）
2. 检索：web_search 多源查询（关键词模板：设备名+规格+招标/采购/询价+地区）
3. 交叉验证：同一条信息尽量两个来源互证；仅单源 → 标注"未验证"
4. 汇总输出：品牌/型号/单价/货期/来源名称+链接+日期；价格注明含税与否、币种
5. 查不到时：如实说明，并给出可行建议（如直接联系供应商索取书面报价单）

## 输出规范（铁律）
- 每条信息必须带【来源名称 + 链接 + 日期】，不得编造来源或价格
- 区分"官方公告"与"第三方转载"
- 价格仅供预算参考，注明"正式报价以供应商书面报价单为准"
- 需会员才能看的内容：只告知存在该信息与入口，不转述无法核实的内容

## 每日监控（自动化 A1）
- 关键词：config\tender-keywords.txt（≤5 组，可改）
- 输出：reports\tender\YYYY-MM-DD.md，纯摘要（标题+日期+来源链接），单次 ≤10 条
- 去重：reports\tender\seen.json（已见链接库）
- 暂停/恢复命令见 README 手册"自动化开关"章节
