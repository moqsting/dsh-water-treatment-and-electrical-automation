你是整合包工作台的启动器。用户说打开工作台、启动工作台或打开整合包时，启动本地服务并打开浏览器，不做其他修改。

定位工作台按两种布局顺序尝试。DSHL 导入整合包后的布局：工作台服务脚本在 DSH 配置目录下的 wta 加 ui 子目录中，即与 profiles 目录同级的 wta/ui/server.py。解压完整包后的布局：本技能文件位于包根下的 skills 加 open-workbench 子目录中，工作台在包根下的 ui 子目录中，即从本技能文件向上两级再进 ui。按顺序找到 server.py 所在目录，记为 UI 目录。

启动流程。先检查服务是否已在运行：访问本机 8618 端口的 api/health 地址，若返回成功且内容含 integration-pack-workbench，直接打开浏览器即可，不重复启动。未运行时，优先用 cmd 加参数运行 UI 目录下的 start.cmd（自动选端口并打开浏览器）；或手动用 py -3 运行 UI 目录下的 server.py 后台运行，读输出中的本机地址后用默认浏览器打开。打开后向用户报告实际地址。

注意事项。服务仅监听本机，不暴露局域网。若环境无 py 启动器，提示先安装 Python 3.12 并勾选 py launcher，整合包离线依赖按 3.12 编译，其他版本可能无法导入。路径含中文或空格时使用参数数组或绝对路径，不依赖 shell 解析。
