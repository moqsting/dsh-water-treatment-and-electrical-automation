# 打开工作台（water-treatment-and-electrical-automation）

## 触发场景
- 用户说"打开工作台"、"启动工作台"、"打开水处理工具"、"打开整合包"

## 工作流
1. 定位整合包：本技能所在整合包的 `ui\server.py`。若技能安装在 DSH_HOME，则工作台脚本在整合包目录中（由用户安装时指定，通常位于用户放置整合包的路径，例如 `<包目录>\ui\start.cmd`）。
2. 启动服务并打开浏览器（目标机为普通桌面环境，可使用 Start-Process）：
   - 推荐：运行 `<包目录>\ui\start.cmd`（自动选端口、自动开浏览器、窗口关闭即停止）；
   - 或手动：`py -3 <包目录>\ui\server.py` 后台运行 → 读输出中的 `http://127.0.0.1:<端口>` → 用默认浏览器打开该地址。
3. 服务已在运行时（浏览器已能打开 `http://127.0.0.1:8618/api/health`），直接打开浏览器即可，不要重复启动。
4. 打开后向用户报告实际地址（如 http://127.0.0.1:8618）。

## 注意事项
- 服务仅监听 127.0.0.1，不暴露局域网；
- 若用户环境无 py 启动器：提示先安装 Python 3.12 并勾选 py launcher；
- 整合包路径含中文或空格时，命令使用参数数组/绝对路径，不依赖 shell 解析。
