# 投标报价清单处理

## 触发场景
- 解析招标文件中的设备清单/工程量清单（xlsx/docx/pdf）
- 汇总比对多家供应商报价
- 生成投标报价表/分项报价表
- 投标清单与报价清单一致性核对

## 工作流（SOP）
1. **清单解析**：定位表格结构（表头识别、合并单元格拆解）→ 规整为统一字段：序号 / 设备名称 / 规格型号 / 材质 / 单位 / 数量 / 备注；
   - PDF 招标文件：优先转 Word 或用 dsh-plugin-anydoc 插件（若已装并实测通过）；应急用截图 OCR（wincu）提取表格
2. **询价比对**：多供应商报价横向比对，按"同参数"归组比价；异常低价/高价标注 ⚠；列示供货期、质保、含税情况
3. **成本测算**：参数化测算（税率默认 13%、运费、安装费、管理费、利润率均可配置）→ 生成测算表
4. **报价表生成**：分项报价表 + 汇总表，输出 xlsx（套用 templates\投标报价表模板.xlsx）
5. **一致性核对**：投标清单 vs 报价清单 diff——漏项、数量差异、型号差异逐行报告

## 工具路线选择规则
| 场景 | 路线 |
|---|---|
| 小批量、需逐项人工审核调整 | dsh-univer-office / dsh-excel-chat 插件（若已装）——GUI 内可视化编辑、审核、导出 |
| 大批量、格式规整、重复性规整 | `integration-pack\scripts\runpy.cmd integration-pack\scripts\quote_tools.py`（openpyxl/pandas 批量处理） |
| 无插件且任务简单 | 直接 Python 脚本 + 输出 xlsx |

## 输出规范
- 金额列保留两位小数；含税/未税分列；币种统一人民币
- 每张报价汇总表注明各供应商名称与报价日期
- 投标报价表按招标文件要求的格式排版，不自行增删清单条目
- 比对报告输出"差异清单"（漏项/数量/型号），供商务决策，不做中标预测承诺

## 注意事项
- 招标清单条目不得擅自合并、拆分或改名（投标废标风险）
- 报价数据必须带来源与日期，不可编造
- 涉及评标办法（低价中标/综合评分）的决策建议仅作参考，最终由投标人决定
