# 电气计算

## 触发场景
- 电缆载流量与电压降校核、短路电流估算、断路器/热继整定、控制柜发热量估算

## 计算模块与要点
1. **电缆载流量**：按材质（铜/铝）、绝缘（YJV/BV）、敷设方式（空气/埋地/桥架）、环境温度修正；内置 data\cable_ampacity.csv（YJV 铜芯常用规格）
2. **电压降**：ΔU = I × L × (R cosφ + X sinφ)；动力回路 ≤5%、照明 ≤5%~7%（按 GB 50052 校核）
3. **短路电流简算**：实用法（变压器容量+阻抗电压 → 低压侧三相短路电流估算），用于校验断路器分断能力
4. **断路器/热继整定**：长延时 Ir ≥ 1.1×工作电流；瞬动与下级选择性配合；热继整定 = 0.95~1.05×额定电流（电机回路按 1.0~1.15）
5. **控制柜发热量**：元件损耗合计 → 通风量/空调选型校核

## SOP
1. 收集输入：负荷功率/电流、电缆长度、敷设条件、变压器参数
2. 每项参数注明依据（规范条文或 data\ 参考表），**规范版本以现行版为准**
3. 输出：公式 + 代入值 + 结果 + 结论（合格/需放大一级电缆/需加保护等）
4. 生成计算书（md/docx），附参数汇总表

## 输出规范
- 单位规范：mm²、kW、kA、V；温度修正系数保留两位小数
- 结论句明确：如"选 YJV-0.6/1kV 4×25+1×16，压降 3.2%，合格"

## 注意事项
- 短路计算为简算，大型/复杂系统需专业软件（如 ETAP）复核
- 结果按现行规范校核：GB 50052/50054/50055/50062/50093、GB 50217
- 数据表：data\cable_ampacity.csv，可自行扩充
