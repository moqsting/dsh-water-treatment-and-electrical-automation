# 水处理工艺计算

## 触发场景
- 曝气需氧量、加药量、污泥产量、水力计算、膜系统设计参数计算
- 编制计算书（需含公式与取值依据）

## 计算模块与要点
1. **曝气需氧量**：碳化需氧量 + 硝化需氧量 + 内源呼吸耗氧，再扣除反硝化回收氧量；按 BOD/氨氮负荷法；结果给出标准状态与设计条件两个值，并建议风机台数与富余系数（10%~20%）
2. **加药量计算**：
   - PAC：按投加率（mg/L，常见 20~60）+ 进水流量 → 日耗量（kg/d）；配药浓度与计量泵选型校核
   - PAM：投加率 0.5~2 mg/L
   - 次氯酸钠（消毒）：按有效氯投加率（5~10 mg/L）× 流量 → 商品量（按有效氯含量 10% 折算）
3. **污泥产量**：初沉污泥 + 剩余污泥（按产率系数 Y 与 SRT）；脱水后泥饼量（含水率 80% 计）
4. **水力计算**：经济流速选管径（压力管 0.7~1.5 m/s、重力流按满度与坡度）、沿程+局部水头损失、水泵扬程校核（静扬程+损失+富余）
5. **膜系统**：UF/RO 通量、回收率、浓水量、膜面积与支数估算

## SOP
1. 收集输入：设计水量（日均/时变化系数）、进出水水质（COD/BOD/氨氮/TN/TP/SS）、工艺类型
2. 明确取值依据：每项参数注明出处（规范条文或 data\ 参考表），**规范版本以现行版为准**
3. 计算并输出：公式 + 代入值 + 结果 + 单位，可复核
4. 生成计算书（md 或 docx），末尾附参数取值汇总表

## 输出规范
- 一律用国际单位制；流量 m³/d 与 m³/h 标注清楚
- 关键中间结果保留 3 位有效数字，最终结果按工程习惯取整
- 与规范不一致的取值必须说明理由

## 注意事项
- 曝气量/加药量受水温、海拔影响，校核时说明
- 计算结果用于方案/初设阶段；施工图设计以注册工程师复核为准
- 常用参数表：data\water_params.csv（药剂投加率、经济流速等，可自行扩充）
