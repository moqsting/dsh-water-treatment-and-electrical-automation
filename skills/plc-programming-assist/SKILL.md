# PLC 程序开发辅助（水处理/电气自动化）

## 触发场景
- 用户要求编写 PLC 程序、控制逻辑或功能块（电机启停、液位联锁、PID 等）
- 用户提供 IO 点表，要求生成程序框架/变量表/地址映射
- 用户要求 Modbus 通讯配置、寄存器表或联调仿真脚本

## 品牌与地址体系（按用户指定品牌路由）
| 品牌 | 系列 | 编程语言 | 地址示例 |
|---|---|---|---|
| 信捷 | XC/XDH/XDM | 梯形图 | X0/Y0、M0、D100 |
| 汇川 | H5U/AM | ST/梯形图（IEC61131-3） | %MX0.0、%MW100 |
| 台达 | DVP/AS | ST/梯形图 | X0/Y0、M0、D100 |
| 西门子 | S7-1200/1500 | SCL/LAD | %I0.0、%Q0.0、%DB1.DBW0 |
| 西门子 | S7-200 SMART | 梯形图 | I0.0、Q0.0、VD100 |
| 三菱 | FX3U/5U | 梯形图 | X0、Y0、D100 |
| 三菱 | Q/L 系列 | ST | M0、D100 |

用户未指定品牌时：先输出「品牌无关的文字控制逻辑 + ST 伪码」，末尾询问目标品牌再转换。

## 工作流（SOP）
1. 需求澄清：设备/回路、控制模式（本地/远程/自动）、联锁与保护条件、品牌系列；
2. 输出【文字控制逻辑】：分模式、分场景描述，标注联锁与保护优先级；
3. 输出【ST 伪码】：品牌无关，变量用位号+功能命名（如 Pump1_Run_Cmd）；
4. 按品牌转换：SCL/ST/梯形图逻辑描述，附变量表（位号 → 地址映射，按上表体系）；
5. 自检清单：双线圈检查、地址范围检查、保护信号优先级、手自动无扰切换、上电初始态；
6. 交付说明：必须经对应编程软件（XDPPro / AutoShop / TIA Portal / GX Works）编译仿真验证后方可上现场。

## 内置功能块模板（调用时按品牌展开）
- **电机启停三模式**（本地/远程/自动）：模式互锁、启动自保持、保护信号（热继/急停）立即停车并封锁自动重启、运行反馈超时报警（默认 5s，可调）
- **液位联锁**：滞回比较（启动液位/停止液位），最小运行/停止间隔可配置，防频繁启停
- **加药泵跟随**：按流量比例/脉冲跟随，冲程与频率控制
- **模拟量处理**：4–20mA → 工程量换算（量程可配）、一阶滤波（系数可调）、断线检测（<3.6mA 报警）
- **手自动无扰切换**：切换瞬间输出保持
- **流量累计**：瞬时量积分/脉冲计数累计，日清零策略
- **鼓风机 DO 调节**：PID（正反作用、输出限幅可配），溶解氧设定值跟踪

## Modbus 联调辅助
- 寄存器表生成：位号 → 功能码（01/02/03/04/05/06/15/16）→ 寄存器地址，注明偏移（40001 与 0 起始两种习惯）
- 从站仿真：`integration-pack\scripts\runpy.cmd integration-pack\scripts\modbus_sim.py --help`（pymodbus 从站，模拟仪表/PLC 供主站联调）
- 4–20mA ↔ 工程量换算对照表

## 输出规范
- 代码块标注品牌+系列；变量命名 = 位号 + 功能后缀
- 每个功能块顶部注释：输入/输出/参数/保护逻辑
- 不承诺"可直接下载运行"；一律注明需经编程软件验证

## 注意事项
- 国产品牌地址体系差异大（信捷 M/D 区、汇川 %M/%MW），转换时逐项核对
- 保护信号必须硬接线 + 程序双保险；禁止仅凭通讯状态做安全判断
- 生成的代码是辅助材料，最终责任在编程软件中的编译仿真验证
