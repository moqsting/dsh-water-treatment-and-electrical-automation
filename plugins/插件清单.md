# 插件清单与安装说明

> 本整合包自带 1 个可选增强插件；其余为备选清单（目标机联网自装）。
> 完整安全审查见 docs/dev/插件安全审查报告.md。

## 一、随包插件（可离线安装）

| 插件 | 版本 | 文件 | 说明 |
|---|---|---|---|
| dsh-univer-office | 0.3.6 | `plugins/vendor/dsh-univer-office-0.3.6.tgz` | 表格/文档/演示的可视化查看与编辑增强（GUI 内操作） |

**安装**（DSH CLI）：

```
dsh plugin --profile <你的 profile 名> add ./plugins/vendor/dsh-univer-office-0.3.6.tgz
```

**注意**：
- 该插件含产品遥测（匿名安装 ID + 平台版本，每日最多一次）。安装后建议关闭：设置插件配置 `telemetry: false`，或设环境变量 `DO_NOT_TRACK=1`；
- 网关仅监听 127.0.0.1 本机回环，无公网暴露。

## 三、安装后实测清单（目标机必做）

1. `dsh plugin --profile <name> add` 安装成功、`dsh --profile <name> --dump-config` 中看到插件层；
2. 重启 DSH 后插件正常挂载（GUI 设置页可见）；
3. 打开一个测试 xlsx 走一遍查看/编辑流程；
4. 任一插件启动失败 → `dsh plugin --profile <name> remove <包名>` 回退，核心能力（自建技能 + 脚本 + 工作台）不受影响。
