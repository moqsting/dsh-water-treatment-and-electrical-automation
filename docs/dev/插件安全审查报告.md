## 二、重要发现（需用户知悉）

1. **modsearch 地址勘误**：社区目录标注为 `Zhiyuan-Fan/modsearch`，该仓库**不存在**（GitHub API/多分支均 404）。真实仓库为 `liustack/modsearch`（与 modlens 同作者）。整合包一律使用 `liustack/modsearch`，警惕任何以 Zhiyuan-Fan 名义出现的仿冒包。
2. **无恶意代码**：6 个插件均无安装期命令执行（preinstall/postinstall）、无 eval/动态执行、无混淆、无凭证外传、无隐藏外发。
3. **遥测说明**：仅 dsh-univer-office 有产品遥测（发往官方 univer.ai/api/telemetry/cli，仅匿名安装 ID + 平台/版本元数据，每日最多一次）。可通过环境变量 `DO_NOT_TRACK=1` 或插件设置 `telemetry: false` 关闭。

## 三、各插件审查详情（摘录）

### 1. dsh-univer-office 0.3.6（本地解压逐文件审查）
- package.json：**无 preinstall/postinstall**；仅 `uninstall` 钩子跑遥测（发送卸载事件，同样可 DO_NOT_TRACK 关闭）
- 运行时依赖 6 个（puppeteer-core、libsql、@puppeteer/browsers 及 2 个 Univer 官方原生绑定），均为官方来源
- 网关仅监听 `127.0.0.1` 本机回环；浏览器截图/PDF 用本机 Chromium/Edge（自动探测）
- [注意] 遥测默认开启（建议关闭）；[注意] 原生模块为预编译二进制（NAPI，跨 Node 版本稳定）
- 兼容性：peerDependencies 显式含 `^0.2.0-rc.1`，本机 0.2.0-rc.2 在范围内 → 预期可装

### 2. dsh-excel-chat 0.38.1（本地解压逐文件审查）
- 无安装脚本；依赖仅 exceljs + fflate；LLM 调用走 DSH 官方 `ctx.llm` 接口，**零外部 fetch**
- 唯一 `spawn` 为调用本机 Excel COM 导出图表 PNG（脚本内容固定、参数独立传参、无注入面）
- 兼容性：peer 声明 `^0.1.0-rc.6`（dsh-attachment/dsh-llm/dsh-system-prompt/dsh-tools）**不含 0.2.x** → 本机安装会 peer 冲突，**暂不纳入**

### 3. dsh-office 0.2.4（GitHub main == npm 0.2.4 供应链一致，SHA 已验证）
- 14 个 Office 工具（xlsx/pdf/docx/pptx 读写）；全库**零网络、零命令执行、零动态代码**
- 写入路径均由模型参数指定（依赖 harness 文件沙箱）
- [注意] npm 发布者与仓库 owner 不一致、commit 未签名；无 engines 声明
- 兼容性：按 0.1.x 开发，0.2.x 需实测（挂载方式为 cordis patch，风险中等）

### 4. dsh-plugin-anydoc 0.1.0（lib 编译产物与 src 逐行一致）
- 插件 JS 零网络；依赖 @firecrawl/anydoc（Firecrawl 官方 napi-rs 原生库，默认**本地转换不联网**；仅显式 `ocr:'hosted'` 才上传，本插件未启用）
- [注意] 无 LICENSE 文件（README 自称 MIT）；未发布 npm、main 分支无版本锁定；原生二进制不可静态审
- 处置：若启用须 vendor 化 + 锁 commit + 补 LICENSE

### 5. modlens 3.26.5（liustack）
- 无安装脚本；依赖仅 commander + undici；**零遥测**
- 网络仅发往用户配置的视觉模型 API 端点；远程图片下载带完整 SSRF/DNS-rebinding 防护
- 子进程仅 spawn 用户本机 CLI（参数数组、无 shell），隔离目录防提示注入
- [注意] recover-paste 读取本地会话存储（功能本体，有所有权校验）；agy 引擎使用 --dangerously-skip-permissions（文档披露）

### 6. modsearch 5.10.5（liustack）
- 无安装脚本；零遥测；SSRF 防护与 modlens 同级；Firecrawl 云端对私网目标有硬阻断
- [注意] `/modsearch/config` 设置路由无内建鉴权（仅限本机 GUI 使用；公网部署需自建鉴权）
- [注意] 默认 Firecrawl keyless 云端抓取公开网页（文档显著披露，可用配置关闭）
- 条件：内网涉密环境关闭 keyless；GUI 仅本机访问

## 四、审查覆盖声明

- 已审查：全部生产代码（含编译产物与源码一致性核验）、package.json、安装脚本、依赖清单、README/SKILL 与代码行为一致性
- 未审查（如实列出）：dsh-office 英文 README（同源中文版已审）；各仓库测试文件与锁文件（不随包分发）；anydoc 的原生二进制内部（Rust，官方包+SLSA provenance）
- 限制说明：本机沙箱无法执行"真实安装+启动"动态实测（需重建 profile 并重启 DSH，且插件安装需联网）。**目标机安装时按操作手册"插件实测清单"逐项验证**，任一插件启动失败即 `dsh plugin remove` 回退，核心能力（自建技能+脚本）不受影响。

## 五、结论

1. 六个候选插件**均未发现恶意代码**，无"必须终止"情形。
2. 纳入整合包：dsh-univer-office（唯一预期兼容 0.2.0-rc.2 的 GUI 增强）；其余为备选清单，附实测步骤。
3. 表格能力以自建脚本（quote_tools.py）为保底，不依赖任何第三方插件。
