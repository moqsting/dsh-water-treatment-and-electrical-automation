# 工具数据契约审计报告 —— smoke test 与工具串联契约

> 起因：`normalize → cost` 串联时，normalize 输出无"单价"字段，cost 抛 pandas KeyError。
> 修复原则：从数据契约层根治（入口 schema 校验 + 契约文档 + 测试覆盖），**不加 try/except 掩盖**，业务逻辑保持不变。

---

## 一、审计发现

| # | 问题 | 根因 |
|---|---|---|
| 1 | normalize 输出（设备表）无"单价"，cost 需要"单价" → KeyError | **工具间无契约定义与校验**；cost 对缺列只做"找到没有→None→pd 崩溃" |
| 2 | "单价(含税)"这类带后缀列名无法被识别 | 旧匹配用精确子串 `k in s` 但只用于 `_find_col`，未覆盖所有入口；新契约校验初版用精确等号，需改为精确+包含两级匹配 |
| 3 | 契约错误输出到 stderr 时编码不一致（GBK） | stderr 未 reconfigure UTF-8 |
| 4 | 无文档说明"哪些工具可直接串联、哪些必须转换" | 契约只存在于代码习惯中 |

## 二、修改清单

### 1. `integration-pack\scripts\quote_tools.py`（核心）

- **契约定义**：新增 `FIELD_ALIASES`（10 类字段的列名别名表）与 `TOOL_SCHEMAS`（normalize/compare/cost/diff 各自的 required / optional / numeric 字段）——契约集中在文件顶部，即代码即文档；
- **入口校验** `resolve_columns` + `check_not_empty`：每个子命令入口统一校验，违反即抛 `SchemaError`（退出码 2），**不再到达 pandas 层**。匹配规则：先精确相等、再子串包含（"单价(含税)"→"单价"、"设备名称"→"名称"）；
- **三类契约错误**（用户要求的格式）：
  - 缺字段：`Missing required field: 单价 / Required by: cost / Available fields: … / 提示: …`（提示含串联建议）；
  - 类型错误：`字段类型错误: 单价 列 'xxx' 含非数值内容 / Required by: cost / 来源: …`；
  - 空数据：`空数据: … 无数据行 / Required by: …`；
- **CSV 输入支持**：`.csv` 按 `utf-8-sig` 读取（Excel 导出的中文 CSV 兼容）；
- **业务逻辑零改动**：normalize/compare/cost/diff 的转换、聚合、测算公式完全保持原样；
- stdout/stderr 均 reconfigure UTF-8。

### 2. `integration-pack\scripts\smoke_test.py`（测试增强）

新增 `expect_fail` 契约断言帮助函数（断言退出码非 0 + 错误信息含全部期望关键词），并新增 6 个场景：缺字段（normalize→cost）、类型错误、空数据、CSV 中文输入、compare→cost 可直连、中文字段保真检查。

### 3. `integration-pack\docs\数据契约.md`（新文档）

每工具 required/optional 输入、输出字段、类型、单位；**串联矩阵**（谁可直接连、谁必须转换）；**Mermaid 数据流图**。

### 4. `integration-pack\README.md`

脚本速查表后追加契约说明段落（不可直连规则 + 入口校验行为）。

## 五、仍存在的限制（如实列出）

1. **契约在 Python 工具层**：DSH 技能（bidding-quote-sheets）对工具的调用仍依赖 Agent 遵循技能说明；若 Agent 直接串联 normalize→cost，工具会拒绝并给出契约错误（兜底有效）。
2. **compare→cost 的语义注意**：比对表同设备多供应商占多行，直接入 cost 会重复计价——契约层面放行（字段齐全），但文档与输出提示"先筛选供应商"；如需硬约束（禁止多行同键），可作为后续迭代。
3. **CSV 编码假设**：按 utf-8-sig 读取；GBK 编码的旧 CSV 会被误读（报契约错误而非静默），需要用户转换后再用。
4. **dxf_parse 输出仍无自动映射**：与 normalize 的列名映射（位号→设备名称）未做自动转换，坚持"不强行串联"原则，由人工整理。
5. 契约校验覆盖 quote_tools 四个子命令；cad_env/dxf_parse/make_templates 输入简单（文件路径），未加同级别校验（dxf_parse 已有文件存在性检查）。
